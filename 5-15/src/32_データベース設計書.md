# データベース設計書

## 1. データベース概要

このデータベースは英単語学習アプリケーションで使用する単語データを管理します。

### 1.1 データベース名

- vocabulary_db

### 1.2 文字コード

- UTF-8

## 2. テーブル定義

### 2.1 words テーブル

英単語と日本語訳を管理するテーブルです。

#### テーブル名: words

| 列名 | データ型 | 制約 | 説明 |
|:-----|:---------|:-----|:-----|
| id | SERIAL | PRIMARY KEY | 単語ID（自動採番） |
| english | VARCHAR(100) | NOT NULL | 英単語 |
| japanese | VARCHAR(100) | NOT NULL | 日本語訳 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 登録日時 |

#### インデックス

- PRIMARY KEY (id)
- INDEX idx_english (english)

## 3. テーブル作成SQL

```sql
-- words テーブルの作成
CREATE TABLE IF NOT EXISTS words (
    id SERIAL PRIMARY KEY,
    english VARCHAR(100) NOT NULL,
    japanese VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- インデックスの作成
CREATE INDEX IF NOT EXISTS idx_english ON words (english);
```

## 4. データ操作SQL

### 4.1 単語の登録

```sql
INSERT INTO words (english, japanese) VALUES (?, ?);
```

### 4.2 単語の取得

```sql
-- 全単語の取得
SELECT english, japanese FROM words;

-- 単語数の取得
SELECT COUNT(*) FROM words;
```

### 4.3 単語の更新

```sql
UPDATE words SET japanese = ? WHERE english = ?;
```

### 4.4 単語の削除

```sql
DELETE FROM words WHERE english = ?;
```

## 5. データ制約

### 5.1 文字列長の制約

- english列：最大100文字
- japanese列：最大100文字

### 5.2 NULL制約

- english列：NOT NULL
- japanese列：NOT NULL
